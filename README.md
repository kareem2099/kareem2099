## 🛠️ What I've Built

| Project | Type | What it does |
|:---|:---:|:---|
| 🚀 [**DotShare**](https://github.com/kareem2099/DotShare) | VS Code | Publish code snippets and content to multiple platforms from one place, with an AI Copilot for writing posts |
| 🔐 [**DotEnvy**](https://github.com/kareem2099/dotenvy) | VS Code | Environment variable manager with encrypted `.env` files and a 4-layer AI secret-leak detection pipeline |

| 🔒 [**DotScramble**](https://github.com/kareem2099/DotScramble) | Linux | Image privacy studio: face and license-plate redaction, batch obfuscation |
| 📡 [**DotFetch**](https://github.com/kareem2099/DotFetch) | VS Code | Lightweight REST/GraphQL client inside your editor |
| 🎵 [**CodeTune**](https://github.com/kareem2099/codetune) | VS Code | Focus environment and audio player for long coding sessions |
| 🌐 [**DotSuite**](https://github.com/kareem2099/dotsuite) | Platform | Distribution hub built with Next.js, Rust (Axum) and multi-language i18n |

Also: [DotCommand](https://github.com/kareem2099/dotcommand) (AI terminal history) and [DotSense](https://github.com/kareem2099/break-bully) (developer wellness), among others.
